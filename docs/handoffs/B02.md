## Запуск из корня репозитория

После обычного bootstrap с миграцией **0004**, без LLM/ключей/PDF/весов:

```bash
docker compose run --rm worker python -m app.ingestion.news update --source cbr-press --limit 5
docker compose run --rm worker python -m app.ingestion.news update --source cbr-events --limit 5
docker compose run --rm worker python -m app.ingestion.news update --source rosstat --limit 5
docker compose run --rm worker python -m app.ingestion.news status
```

Локальная альтернатива при настроенной DATABASE_URL: `make news-update
NEWS_ARGS='--source all --limit 5'`, `make news-status`. Источники фиксированы;
произвольного --url нет. Лимит 1–50 статей, первые 100 RSS items максимум.
Команда возвращает JSON состояния; partial/error — exit 1. Источники независимы:
ошибка Росстата не удаляет новости ЦБ. Scheduler и HTTP при startup отсутствуют.

Авторизованный пользователь с grants текущей компании:

- `GET /api/v1/news?source=cbr&limit=20` — текущие live Event, включая evidence_ids;
- `GET /api/v1/news/sources` — время попытки/успеха, статус, ошибка и счётчики;
- `GET /api/v1/evidence/{id}` → document_version_id;
- `GET /api/v1/sources/{document_id}` — сохранённый текст, publisher, date и открываемый url.

`news.read` и `sources.read` проверяются сервером. Для публичного Document нужен
записанный news registry, а не только company_id=NULL; закрытые company documents
остаются закрытыми. Выдаётся JSON/plain text, raw HTML не исполняется. Старый
synthetic `/feed` и fixture analysis не переключаются на live автоматически.
CLI `python -m app.ingestion.news show <document_id>` читает сохранённый Document.

## Версии и даты

RSS → article fetch → нормализованные title/text/URL/GUID/date → одна атомарная
публикация SourceVersion/Document/Event/Evidence. HTTP выполняется вне DB-транзакций;
session advisory lock сериализует одну ленту, короткий publisher lock — публикации.

Идентичность: publisher + canonical URL либо известный GUID. GUID aliases сохраняются
даже при неизменившемся тексте (до 100 на статью; конфликт идентичностей — reject).
URL после проверенных redirects, без fragment, query сохраняется. Body/title/date/URL
сверяются по нормализованному SHA; косметический HTML не создаёт версию. Новый текст
или metadata создают новые IDs; A→B→A тоже создаёт третью версию. Старые records
не переписываются, новый Document.supersedes_id ссылается на предыдущий.

SourceRef.sha256 — исходные HTML bytes; parser_version=news-2 (ранее news-1),
rule_version=news-topics-1. SourceVersion.available_at — **первое наблюдение этой
версии**. published_at не подменяет available_at. RSS pubDate требует timezone;
при отсутствии даты допускается явный article metadata/time. Date-only трактуется
как день Europe/Moscow с date_precision=day; это не точное время публикации.
Invalid/naive/future/conflicting dates и отсутствие текста отклоняют статью,
сохраняя предыдущую версию. Event.event_at — публикация, event_time_source=publication,
не выдуманная дата экономического события.

Evidence — точные части сохранённого текста по chars:start:end, quality=unverified.
value_kind=unknown: целый текст может смешивать факты/прогнозы/мнения,
поэтому тип экономического утверждения из наличия публикации не выводится.
Claims, числа/метрики, банковская позиция и персональная релевантность не генерируются.
Только прозрачные keyword topics (rates/inflation/statistics/regulation), возможен [].
Семантическое объединение разных новостей/извлечение economic event key не реализовано.

При коррекции зависимые analyses помечаются delivery.stale=true с reason
news_source_corrected:<source_version_id>; проверяются event, source_versions,
temporal dependencies и evidence. GET analysis повторяет проверку, включая поздно
сохранённый результат старого run. Исторические evidence доступны; отдельного кеша
генераций пока нет. Будущий engine не должен считать старую версию свежей.

## Fetch и отказ источника

HTTPS 443, exact allowlist cbr.ru/www.cbr.ru/rosstat.gov.ru/www.rosstat.gov.ru;
credentials/control chars/другие порты/схемы запрещены. Каждая redirect-цель и DNS
проверяются заново; смена издателя запрещена. Все DNS answers должны быть global
unicast; соединение закреплено за проверенным IP, Host/SNI и TLS hostname verification
сохраняются. Нет env proxy, HTTP redirect follow или скрытого retry.

[CA Минцифры](../../config/certs/README.md): root и два intermediate PEM лежат в
config/certs и дополняют certifi **только** для двух разрешённых hosts Росстата.
В ОС/глобальное хранилище/LLM сертификаты не устанавливаются; verify/hostname
verification не отключаются. Сроки, отпечатки и процедура обновления — по ссылке.
При замене PEM нужен перезапуск процесса и пересборка образа.

Публикации Росстата могут redirect с `/central-news/document/<id>` на
`/storage/mediabank/<file>.html`. Для подтверждённого LibreOffice XHTML с
`DCTERMS.source=http://xml.openoffice.org/odf2xhtml` читается body с теми же
исключениями исполняемого контента. Этот fallback ограничен Росстатом и указанными
путями. DCTERMS.issued/modified без timezone не подменяют дату публикации из RSS.
Таблицы сохраняются как последовательность текста, не как извлечённые метрики.

Общий timeout DNS/redirect/body — 10 s, максимум 3 redirects, 2 000 000 bytes,
проверяются Content-Length, фактический поток и content type RSS/HTML. Encoding
compression отклоняется; DTD/entities/UTF-16 RSS запрещены. HTML script/style/iframe/
nav/исполняемые блоки удаляются; тела ограничены 200k characters и 40k DOM nodes.

last_success_at изменяется только при успешной/частично успешной обработке;
last_attempt_at/error/rejected описывают текущую попытку. При недоступности данные
не удаляются и не выдумываются новые даты. State хранится в news_sources.

## Общие изменения и передача M

DTO **1.1.0**: у Document добавлены optional url/guid/supersedes_id/date_precision;
у Event — topics/event_time_source с безопасными defaults; добавлен NewsSourceState.
Evidence.value_kind дополнен unknown для неклассифицированных сырых цитат;
старые fact/forecast/opinion не меняются, live news используют unknown/unverified.
JSON Schema/OpenAPI/examples пересобраны. Старые payload читаются с defaults;
consumers используют обновлённые contracts. Новые маршруты не требуют изменения UI.

Миграция 0004 добавляет news_sources/news_items/news_versions и разрешает NULL
company_id у публичных документов; grants не создаются. PDF/pgvector/FTS не менялись.
Nullable docs не становятся частью company-scoped bank retrieval автоматически:
это внешняя новостная лента, а не банковские research chunks. Merge новых миграций
должен сохранять один Alembic head. Downgrade с public data отказывается удалять её.

## Будущие источники

Интерфакс (`https://www.interfax.ru/rss`) и EIA
(`https://www.eia.gov/rss/todayinenergy.xml`) **не подключены** к FEEDS/allowlist.
[План §4.3](../plan.md#43-источники-и-обновление) фиксирует шаги добавления,
проверку условий использования/перепечаток и отдельный source acceptance.
EIA — зарубежный background; влияние на клиента крайне косвенное и условное,
требует подтверждения канала. Его данные/анализ, банковские доказательства и
гипотезы модели должны оставаться различимыми; численный эффект не переносится
на российского клиента по одной энергетической новости.
