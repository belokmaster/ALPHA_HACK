## Подготовка без startup download

Базовый synthetic путь не требует тяжёлых библиотек. Необязательный extra `ml`
закреплён в pyproject.toml/uv.lock: CPU torch, sentence-transformers/transformers,
NumPy, pypdfium2/Pillow/pytesseract и поддержка настроенного SOCKS proxy.
Базовые locked версии не обновлялись. Python 3.12; проверен Linux x86_64.

```bash
uv sync --frozen --extra ml
# Явная бесплатная подготовка pinned weights/tokenizer. Не startup и не bootstrap:
python -m scripts.prepare_e5 --download
# Проверка/повторная фиксация локального manifest без сети:
python -m scripts.prepare_e5
```

`models.lock` содержит revision, SHA-256 всех файлов, 384/FP32/512 tokens,
mean pooling/L2, query:/passage:, MIT. Веса в models/ игнорируются Git.
`LocalE5Encoder` проверяет manifest и hashes, использует только локальный каталог,
safetensors и trust_remote_code=False; runtime config не может разрешить download.
При отсутствии файлов — явный lexical_fallback; vector acceptance не засчитывается.
Загрузчик весов не использует API-ключи, token=False; никакого LLM/embedding API.

OCR требует Tesseract **5.3.0**, rus+eng traineddata. Воспроизводимый Debian runner:

```bash
docker compose build app
docker build -f src/Dockerfile.ml -t alfa-ml:local .
# CLI внутри образа: /app/.venv/bin/python; исходники/данные можно смонтировать в /workspace.
```

Образ ML расширяет существующий foundation image; Debian package versions зафиксированы.
Hashes traineddata/renderer/OCR versions/DPI сохраняются с page cache. Образ не содержит
PDF/CSV/веса и не загружает их при запуске. При работе из worktree host bind path должен
соответствовать пути, видимому Docker daemon; для SELinux можно использовать временный
container `--security-opt label=disable`, не меняя метки исходных файлов.

## M02: явный атомарный импорт только банковского корпуса

Положить исходные **девять** банковских PDF в raw/pdf/ (локальные inputs, не Git).
Наличие рядом задания/инструкции ключей не влияет: allowlist + все hashes/page counts
из config/bank_corpus.json проверяются до публикации. Отсутствие хотя бы одного файла,
hash mismatch, пустая страница, отсутствующий OCR или ошибка страницы — fail closed.
Нет fallback «verified spans only» для отсутствующего PDF.

```bash
python -m app.ingestion.pdf --pdf-dir raw/pdf
# Явный apply с DATABASE_URL нужной БД, не startup:
python -m app.ingestion.pdf --pdf-dir raw/pdf --apply
# Явный отказ от embeddings (только FTS; не vector acceptance):
python -m app.ingestion.pdf --pdf-dir raw/pdf --apply --lexical-only
```

CSV больше не нужен для запуска PDF этапа. Старый scripts/import.py делегирует
опциональный PDF этап той же команде; общий bank scope — __public__, другой scope
отклоняется. Рабочие БД автоматически не мигрируются/перестраиваются.

OCR и CPU embeddings выполняются до SQL-транзакции. Публикация всех 9 SourceVersion,
Document, Evidence и embeddings — одна транзакция под advisory lock. Повтор сверяет
неизменяемые payload; несовпадение той же версии — ошибка, а не overwrite.
Source/Document/Evidence IDs зависят от PDF SHA, corpus config и parser version.
Изменение bytes/config создаёт новые IDs, старые данные сохраняются. При смене OCR
runtime с иным текстом нужно повысить parser/config version; collision не перезапишет
историю. Весь corpus config заморожен в памяти на один prepare/import.

Общебанковский scope — типизированный **не клиентский** sentinel CompanyProfile
(status=stub, client_type=unknown, без выручки/признаков/прав), чтобы сохранить старый
NOT NULL FK без новой миграции. Он не участвует в visible_profiles. Публичность требует
одновременно scope, versioned doc ID из corpus registry и SourceVersion.import_version
pdf-corpus-2. Произвольные __public__/NULL документы не становятся общими. Это совместимо
с nullable news storage B02: оно остаётся отдельным registry/domain=live.

Всем supplied PDF оставлен **available_at=null**, также SourceVersion/Evidence.
Время импорта не заменяет историческую доступность. Даты публикации из шапок заданы
с precision=day в config; midnight Europe/Moscow — представление дня, не доказанный час.
Gold digest: published_at=null, доступность не выводится из «Август»/данных на 07.09.
Неподтверждённые data_as_of удалены. Strict_as_of исключает все эти материалы;
snapshot_demo допускает их с явным warning и не называется backtest.

## M03: контракт, ACL и закрепление задания

Публичный contracts.ports.EvidenceRetriever.search(context, request, query)
по-прежнему возвращает **list[Evidence]**, не DetailedSearchResult. DTO/ports не расширены
флагом из текста запроса. Допуск ретроспективы задаёт доверенный backend при создании
инструмента, поэтому он доступен и через неизменённый port:

```python
from app.retrieval.service import HybridRetriever, LocalE5Encoder, RetrievalPolicy
retriever = HybridRetriever(engine, LocalE5Encoder(),
                            policy=RetrievalPolicy(allow_historical=True))
items = await retriever.search(context, analysis_request, "исторический обзор стали")
# Для диагностики/метаданных:
result = await retriever.search_with_meta(context, analysis_request, query,
                                         mode_preference="hnsw", explain=True)
```

Ретроспектива не отключает ACL/availability/domain/published_at. Search копирует request/
context на входе; сравнивает context ID/version/company/role/preferences/acl_version
с сервером и request.context_version. Реальные grants читаются заново, caller grants
не доверяются; отзыв даёт deny даже при старом UserContext.

FTS (русский/английский tsvector, GIN, ts_rank_cd) — не BM25. 20 кандидатов на канал,
RRF k=60, дедуп по quote SHA, ≤3 чанка на страницу, максимум 8 по port. Exact выключает
index/bitmap scan локально. HNSW включает iterative_scan=strict_order/ef_search=40;
для малой коллекции enable_seqscan=off **явно заставляет** ANN mode. Это не утверждение
о выборе планировщика по умолчанию. EXPLAIN ANALYZE BUFFERS выполняет тот же запрос
с теми же ACL/time filters и фиксирует idx_evidence_hnsw; secondary e.id sort убран
из ANN ORDER BY, поскольку он мешал использованию cosine index. Vector failure
откатывает savepoint и возвращает честный lexical_fallback.

Не добавлялись M04, общий engine, новый UI/API или доступ к PDF через live news registry.
Проводка bank document links в общий UI/API относится к будущей интеграции; B02 routes
не переписывались. Gateway/worker/budget/CSV storage/migrations не менялись.
