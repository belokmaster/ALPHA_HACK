# Разборы и рубрика M01

Версия 2.0. [G1/G2/G3](manual-cases.json) — авторские разборы агента, сверенные с
CSV и изображениями PDF, **не независимая человеческая разметка**. Нумерация CSV
включает заголовок (первая запись=2). Проверка: `python -m scripts.verify_manual_inputs`.

Шесть вопросов оцениваются человеком 0/1 каждый: событие с правильным источником;
связь с разрешёнными признаками клиента; условный механизм с альтернативами;
конкретный полезный вопрос/действие; применимость позиции банка или явный not_found;
проверяемые основания и ограничения. Указать основание каждого балла и критические
ошибки. Незаполненный блок допустим лишь с конкретным объяснением нехватки данных.

Claim.kind и Claim.origin различаются: факт внешнего издателя, bank_analysis,
вывод модели и hypothesis с условиями/альтернативами. Банковское доказательство
не требуется для каждого инсайта (Q&A 43–44). Факт/bank_view требуют подходящего
page/span evidence; персональный вывод — релевантных разрешённых feature refs.
Не требовать оба массива для любого утверждения. Наличие refs не доказывает entailment.

Критические ошибки: неподтверждённое число/единица/субъект/горизонт; причинная
подмена; чужие данные; ложный bank_view; перенос доли плавающего долга рынка на
клиента; forecast как факт; период платежей с вымышленным концом; future leakage.
Любая критическая ошибка проваливает сценарий независимо от суммы баллов.

CEO/CFO одной компании: факты/банк/права неизменны, различаются акцент и вопрос.
U_11496: LOA=0 не доказывает отсутствие любого финансирования; LEA=1 сохраняется.
G2: наличие платежа не доказывает поставщика/перевозчика, нет знаменателя расходов.
G3: ОКВЭД 46.72 не доказывает золотой ассортимент. В strict_as_of все PDF с
неподтверждённым available_at исключаются; snapshot_demo не исторический backtest.

No-answer: background кандидаты разрешены. Retrieval отдельно измеряет утечки,
а downstream должен выдать bank_evidence_status=not_found без применимого тезиса.
Пустая выдача не обязательна; отсутствие запрещённых docs не доказывает корректной
атрибуции банка. До M04 downstream-метрика не проверена.

`eval/splits.json` и 11 существующих запросов — **exposed development smoke**,
не полный gold. Их уже видели при разработке; старый test не считается независимым.
